# shot

Снимки экрана под [niri](https://github.com/YaLTeR/niri) без установки
лишнего. Обёртка над `grim` и `slurp`, которые на машине уже стоят.

Зачем ещё одна обёртка: голый `grim` требует самому придумывать имя файла,
каталога для папок не было, и превью с подписью не делал.

## Что умеет

```bash
shot s            весь экран
shot r            область — выделяешь мышью
shot d            список мониторов
shot d DP-2       один монитор по порту
shot d Xiaomi     один монитор по имени
shot t 5          снимок с таймером
shot p            снимок в буфер обмена
shot last         путь последнего снимка
shot open         открыть папку
```

Каждый снимок уходит в `~/Pictures/Screenshots/<год>/`, рядом уменьшенная
копия и подпись времени в углу. Если есть `wl-copy` — снимок дополнительно
ложится в буфер.

```
2026-10-13_10-01-09-d-DP-2.png
2026-10-13_10-01-09-d-DP-2_small.png
```

Порт монитора попадает в имя специально: без этого два снимка разных
мониторов в одну секунду затёрли бы друг друга.

## Установка

```bash
install -d -m 755 ~/Pictures/Screenshots
install -m 755 shot ~/.local/bin/shot
```

Нужен `grim` и `slurp` (`xbps-install -Syu grim slurp`), `ffmpeg` — для
подписи и превью, но не обязателен: без него снимки просто получаются без
дополнительных файлов. `wl-copy` — для буфера, тоже необязателен.

## Что не работает: снимок окна

```
$ shot w
shot: niri 26.04 не отдаёт снимок окна.
Весь экран работает: shot s
Область: shot r
Причина — grim -T опирается на ext-image-capture, которого в этой версии нет.
```

`grim -T` требует расширение `ext-image-capture`. На niri 26.04 его нет,
обойти нельзя. Остаются `s`, `r` и `d`.

Заодно: niri блокирует `screen-capture` для KeePassXC — так окно с
паролями в снимок не попадёт, даже если бы `-T` работал.

## Особенности niri, на которые опирается скрипт

**Списка мониторов у `grim` нет.** Ни `-l`, ни `-d` в этой версии не
существует. Скрипт берёт имена и координаты из `niri msg outputs` и снимает
через `grim -g X,Y ШИРИНАxВЫСОТА`.

**`niri msg focused-window` не умеет JSON.** Печатает `Window ID 7: (focused)`,
id вытаскивается регуляркой.

**Порядок строк в выводе `niri msg outputs`:** `Logical position` идёт
**перед** `Logical size`. Парсер обязан это учитывать, иначе запись
выбрасывается как неполная.

## Приватность

Снимок содержит то, что на экране. Пароли, токены, личное — не класть в
архивы, которые уезжают с машины.

## Тесты

```bash
tests/smoke.sh
```

Проверяет, что скрипт не падает на справочных командах и списке мониторов.
Полноценных снимков в тестах нет: для них нужен настоящий терминал.

## Навык

`skills/shot/SKILL.md` — тот же навык, что стоит в `~/.config/opencode/`.
Читать его нужно до прямого вызова `grim`: там записаны все грабли выше.
