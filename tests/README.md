# Тесты

`smoke.sh` — единственный проверяемый без терминала тест: убеждается, что
`shot --help`, `shot d` и `shot last` не падают и возвращают осмысленный вывод.

Проверка «взглядом»: запустить `shot s` в настоящем терминале и убедиться,
что PNG открывается, превью создаётся, подпись времени на месте. Это
единственный способ проверить вывод в графику, автоматизации он не
поддаётся.
